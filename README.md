# The World in One Day

A 1024 × 1024 newspaper front page dated Thursday 19 November 2026, with 33 supplied stories and illustrations drawn in Pillow. The supplied claims, dates, and attributions were reproduced without independent verification.

- Run `python3 draw.py` to regenerate `entry.png`.
- Run `python3 main.py` to copy the PNG to `MAKEFUN_OUTPUT_DIR`, which defaults to `output`.
